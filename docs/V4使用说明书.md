# Bamboo Weave Studio V4 使用说明书

这份说明书面向第一次使用的用户。不需要会编程，按下面的步骤点击和拖动即可。

## 1. 先认识界面

打开网页后，画面分为四个主要部分：

- **左边纹样库**：选择平编、雪花编、菱形、六角眼等纹样。
- **左侧细工具栏**：选择、切割、交点切换、新增竹条等工具。
- **中间画板**：放置区域、竹条和过渡结构。
- **右边属性面板**：修改当前选中对象的数值、颜色和状态。

工具按钮上的字母是快捷键。例如，按键盘上的 `V` 等于点击“选择工具”。

## 2. V4 推荐体验顺序

1. 用 `R` 矩形工具在画板上拖出一个区域。
2. 在左边纹样库选择一个纹样。
3. 在右边 `Direction Layers` 中调整方向、密度和间距。
4. 用 `C` 交点工具切换一个交点的上下关系。
5. 用 `X` 切割工具切断几根竹条。
6. 用 `V` 拖动一根竹条或整个方向层。
7. 用 `A` 节点工具修改竹条路径。
8. 用 `S` 手动画一根新竹条。
9. 切换到 `3D Realistic` 查看高度和穿插效果。
10. 保存 JSON，再导出 PNG。

## 3. 切换一个交点的 Over / Under

`Over / Under` 表示两根竹条交叉时，哪一根在上面、哪一根在下面。

### 操作方法

1. 点击左侧工具栏的圆点图标，或按 `C`。
2. 画板上的交点会出现可点击的圆形范围。
3. 点击想修改的交点。
4. 该交点会立即交换上下关系。
5. 右边会出现“已选交点”，点击“交换 Over / Under”可再切换一次。

### 怎样算成功

- 2D 中交叉处最上面的竹条会变化。
- 切换到 3D 后，相同交点的高度关系也会变化。
- 这个修改会被单独保存，不会改掉整个纹样的交织规则。

## 4. 用切割线切断竹条

### 最简单的切割

1. 点击左侧剪刀图标，或按 `X`。
2. 在画板上按住鼠标左键，拖出一条红色切割线。
3. 会被切到的竹条显示为红色，切割线旁边显示数量。
4. 在右边选择“适用范围”和“切割模式”。
5. 点击“应用切割”。

如果不想保留这次切割，在应用前点击“取消”；应用后可使用顶部的 Undo 撤销。

### 适用范围

- **全部竹条**：切割线经过的所有区域都会被切割。
- **当前区域**：只切割当前选中区域里的竹条。请先用 `V` 选中区域，再切换到 `X`。
- **当前方向层**：只切割某一个 Direction Layer。请先点击右边的方向层卡片，看到卡片高亮后再使用 `X`。
- **同方向竹条**：切割画板上和当前方向层角度相同的竹条。
- **已选竹条**：只切割已选中的单根竹条。

### 切割模式

- **分割并保留两侧**：竹条真正变成两段，两段都保留。
- **只保留左侧 / 只保留右侧**：切断后只留一边。
- **删除左侧 / 删除右侧**：删除指定一边，保留另一边。

左右以“从你开始拖动的点，朝松开鼠标的点看过去”为准。如果方向不符合预期，可立即 Undo，再反方向画一次切割线。

## 5. 移动整个 Direction Layer

Direction Layer 是同一方向的一组竹条。例如，0° 水平竹条是一层，90° 垂直竹条是另一层。

### 用数值精确移动

1. 用 `V` 选中一个区域。
2. 在右边找到 `Direction Layers`。
3. 点击要编辑的方向层卡片，卡片会高亮。
4. 修改“水平偏移”和“垂直偏移”。

### 在画板上直接拖动

1. 点击方向层卡片，让它高亮。
2. 保持 `V` 选择工具。
3. 拖动该方向层中的任意一根竹条。
4. 同一层的所有竹条会一起移动。

再次点击已高亮的方向层卡片，可取消整层选择。勾选“锁定方向层”后，就不会被误拖动。

## 6. 移动和修改单根竹条

### 移动单根竹条

1. 确认 Direction Layer 卡片没有高亮。如果正在高亮，再点一次取消。
2. 使用 `V` 选择工具。
3. 直接按住一根竹条并拖动。
4. 只有这一根竹条会移动。

选中竹条后，右边“单根竹条”中还可以修改：

- 颜色覆盖。
- 宽度覆盖。
- X / Y 偏移。
- 3D 高度。
- 锁定竹条。

点击“单根竹条”标题右边的回转箭头，可清除这根竹条的手动修改，恢复自动生成结果。

## 7. 编辑单根竹条的路径

1. 按 `A` 或点击节点选择工具。
2. 点击想修改的竹条。
3. 竹条路径上会显示蓝色控制点。
4. 拖动控制点，改变竹条的起点、终点或中间路径。

这是手动路径覆盖。改变其他竹条时，这根竹条不会自动跳回原位。需要恢复时，使用右边的重置按钮。

## 8. 手动新增一根竹条

1. 先选中目标区域。
2. 如果希望新竹条属于某个方向层，先点击该 Direction Layer 卡片。
3. 点击钢笔线条图标，或按 `S`。
4. 在画板上按住鼠标，按想要的路径拖动。
5. 松开鼠标，新竹条即会建立。

新竹条的属性中会显示 `Manual`，代表它是手动添加的，不会被纹样引擎自动删掉。

## 9. 新增 Direction Layer

1. 用 `V` 选中一个区域。
2. 在右边 `Direction Layers` 标题右侧点击 `+`。
3. 新方向层会立即出现，并生成一组可计算竹条。
4. 调整角度、间距、条宽、条数、密度和颜色。
5. 新方向层和已有方向层之间会自动建立 Crossing Rule。

点击方向层上的垃圾桶可删除该层。为避免区域完全没有结构，最后一个方向层不能删除。

## 10. 3D 高度和爆炸视图

### 调整高度

- 选中 Direction Layer，修改“3D 高度”，可以整层上移或下移。
- 选中单根竹条，修改“3D 高度”，可以只移动这一根。

### 爆炸视图

1. 切换到 `3D Realistic`。
2. 点击右上角“爆炸视图”。
3. 不同方向层会在高度上分开，方便查看结构。
4. 点击“合并视图”恢复正常效果。

爆炸视图只是检查方式，不会改变项目数据。

## 11. Undo / Redo、自动保存和文件保存

- 顶部向左弯箭头是 **Undo（撤销）**。
- 顶部向右弯箭头是 **Redo（重做）**。
- 区域、方向层、单根竹条、切割和交点修改都会进入操作历史。
- 网页会在当前浏览器中自动保存，但清理浏览器数据可能会丢失自动保存。
- 完成重要设计后，建议使用顶部保存按钮导出 `.bamboo.json` 项目文件。
- “读取”可重新打开 V3 或 V4 项目文件。V3 文件会自动升级为 V4。

## 12. 导出 PNG

1. 切换到 `2D Structure`。
2. 调整到想导出的最终效果。
3. 点击顶部的 PNG 导出按钮。
4. 浏览器会下载一张 PNG 图片。

PNG 是结果图，不能再回到软件中继续编辑。需要继续编辑时，请同时保留 JSON 项目文件。

## 13. 常见问题

### 点击交点没反应

确认左侧工具栏中选中的是 `C` 交点工具，而不是 `V` 选择工具。

### 拖动一根竹条时，整层都动了

说明 Direction Layer 卡片正在高亮。再点击一次该卡片取消整层选择，然后再拖动单根竹条。

### 切割后留下了错的一边

点击 Undo，再从反方向拖出切割线；或在右边将“保留左侧”换成“保留右侧”。

### 单根竹条改得太乱，想恢复

选中这根竹条，点击右边“单根竹条”标题旁的回转箭头。

### 换电脑后自动保存不见了

自动保存只存在原浏览器中。请在原电脑上导出 JSON，再把 JSON 文件发到新电脑读取。

## 14. 快捷键表

| 快捷键 | 功能 |
| --- | --- |
| `V` | 选择、移动区域或竹条 |
| `A` | 编辑区域节点或竹条路径节点 |
| `R` | 画矩形区域 |
| `P` | 画多边形区域，按 Enter 完成 |
| `B` | 画笔区域 |
| `E` | 删除区域 |
| `L` | 新增结构过渡 |
| `G` | 密度渐变 |
| `C` | 交点 Over / Under 切换 |
| `X` | 竹条切割 |
| `S` | 手动新增竹条 |
| `H` | 平移画板 |
| `Space + 拖动` | 临时平移画板 |
| `鼠标滚轮` | 缩放画板 |
| `Delete / Backspace` | 删除当前选中的区域或过渡 |
| `Esc` | 取消正在绘制的区域或切割线 |
